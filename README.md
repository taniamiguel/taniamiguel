## 📂 Projetos em destaque

### ⭐ [Pós-Consulta: automação de avaliações no Google](https://github.com/taniamiguel/pos-consulta-avaliacoes-google) · *projeto real em produção*
Sistema que criei e uso na clínica onde trabalho para pedir avaliações no Google após cada atendimento. Ele extrai a agenda, padroniza os telefones, remove quem já avaliou e prepara as mensagens de WhatsApp com o link.
- **Resultado:** as avaliações no Google subiram de **110 para 204 (+85%) em 1 mês**.
- **Ferramentas:** Python, Node.js, Playwright, Google Sheets e Docker

### 🧹 [Pipeline de dados de e-commerce: PostgreSQL → Python → Power BI](https://github.com/taniamiguel/pipeline-etl-postgresql)
Limpeza de uma base de vendas suja em três camadas (raw, stage e final) e cálculo de 5 indicadores (receita líquida, margem bruta, devolução, atraso na entrega e ticket médio) em SQL, Python e Power BI.

Ao revisar o projeto que fiz num curso, com parte do código gerada por IA, descobri que a data de entrega vinha com dia e mês invertidos e que algumas medidas DAX misturavam bases diferentes.
- **Resultado:** o atraso médio correto é de **0,36 dia**, e não 115 dias como mostrava o painel original. A receita líquida real é **17% menor** que a calculada no curso.
- **Ferramentas:** PostgreSQL, Docker, Python (Pandas, SQLAlchemy, Matplotlib) e DAX

### 🛒 [Análise de e-commerce com SQL: Olist](https://github.com/taniamiguel/analise-ecommerce-olist-sql)
10 perguntas de negócio respondidas com SQL sobre **99 mil pedidos reais** de um marketplace brasileiro.
- **Insights:** atrasos de mais de 7 dias derrubam a nota média do cliente de 4,29 para 1,70, e 97% dos clientes compram uma única vez.
- **Ferramentas:** SQL (CTEs e funções de janela), SQLite e Python

### 📊 [Dashboard de Performance: Facebook Ads](https://github.com/taniamiguel/marketing-analytics-dashboard)
Dashboard interativo que compara campanhas por gasto, CTR e CPC.
- **Insights:** a campanha Lookalike teve CTR cerca de 30% maior e CPC cerca de 16% menor. Também apontei uma possível falha no rastreamento de conversões.
- **Ferramentas:** Python, Pandas, Dash e Plotly · [ver online](https://marketing-analytics-dashboard.onrender.com)

### 🐾 [Dashboard de Vendas: Gatito PetShop](https://github.com/taniamiguel/petshop-gatito-powerbi-dashboard)
Análise de faturamento por período, bairro e perfil de cliente, com filtros cruzados entre os visuais.
- **Ferramentas:** Power BI, Power Query, DAX e modelagem de dados
